## AI 보고서 엔진 완료 안내

`PANG3/ai/` 폴더에 **현장 보고서 자동 생성 엔진** 만들어 두었습니다.

### 하는 일
- 위치도 + 현장사진(N장) + 메인코멘트 → **HWP 호환 보고서** 자동 생성
- Gemini로 **공문체 현장 분석문** (`ai_refined_content`) 생성
- Java 백엔드에서 **Python 프로세스 1번 호출**로 연동

### 백엔드에서 해야 할 것
1. 현장 저장 API에서 이미지를 서버에 저장
2. 저장된 **절대경로**로 JSON 만들기
3. `ai/app.py` 실행 → stdout의 `@@AI_RESULT@@` JSON 파싱
4. `ai_refined_content`, `report_file` DB 저장

**상세 스펙:** `ai/INTEGRATION.md` 참고

### 입력 JSON 예시 (핵심만)
```json
{
  "location_name": "가락타운",
  "task_category": "보행등, 경관조명",
  "main_comment": "23:00(현행) → 24:00(변경) 소등시간 연장",
  "field_memo": "현장 메모",
  "map_image": "/서버/절대경로/map.jpg",
  "field_photos": [
    { "path": "/서버/photo1.jpg", "comment": "현장사진(2)|옹벽 경관조명" },
    { "path": "/서버/photo2.jpg", "comment": "현장사진(2)|인도 보행등" }
  ],
  "output_dir": "/서버/reports"
}
```

### 사진 코멘트 규칙
- `현장사진(2)|캡션` → 표 제목 "현장사진 (2)", 사진 아래 캡션
- `전` / `중` / `후` → 섹션 제목으로 사용
- 한 줄만 쓰면 캡션으로 처리

### 로컬 테스트
```bash
cd ai
source venv/bin/activate
pip install -r requirements.txt
./run.sh samples/garak_sample.json
# → output/ 폴더에 .hwp 생성
```

### 서버 필요 사항
- Python 3.11+, `ai/` 폴더 + venv
- `GEMINI_API_KEY` 환경변수 (SSM 등 — **저는 키 건드리지 않음**)
- 보고서 output 폴더 쓰기 권한

### 프론트 / 기타
- 프론트 `FieldActionScreen` → 백엔드 `field-report` API 연결은 **백엔드+프론트** 작업
- AI 쪽은 **JSON만 맞으면** 동작합니다
