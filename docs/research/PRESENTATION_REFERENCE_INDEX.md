- [집사의고민 4차 데모데이 회고](https://developer-nyong.tistory.com/64): 요구사항·구현 보고와 서비스 소개의 비중을 고민한 기록.

- [SW중심대학협의회 2024 우수작품경진대회 공식 안내](https://imweb6600108129.imweb.me/72/?bmode=view&category=&idx=20429705&q=YToxOntzOjEyOiJrZXl3b3JkX3R5cGUiO3M6MzoiYWxsIjt9&t=board): 개발배경·구성·개발내용·구현결과·기대효과 등의 항목 참고. FairDay 규칙이 아님.

## 접근이 제한돼 주 근거에서 제외한 것

- FairDay 원래 공고: https://dauswcenter.com/home/noticeView.do?NOTICE_ID=139 — 접속 불가. 행사 조건은 사용자가 제공한 공고 본문·포스터로 확인.
- 일부 대학 졸업작품 게시판과 Google Slides 링크 — 검색 노출과 본문 열람 상태가 달라 실제 장표 분석의 근거로 쓰지 않음.
- 농식품 공공데이터 포털의 과거 수상작 발표자료 첨부 공지 — 공지 본문은 열렸으나 첨부 원본을 확보하지 못해 슬라이드 구성 분석에서 제외.
- SW중심대학협의회의 일부 개별 작품 소개 — 접근 제한으로 실제 발표 장면 분석에서 제외.

링크는 확인 당시의 공개 상태이며 이후 변경될 수 있다. 원문 관찰과 PANG3용 제안을 구분해 사용한다.
