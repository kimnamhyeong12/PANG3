# 다선초 카카오 SDK 장소 ID A/B 실측

2026-10-26. 연결된 SM-S908N에서 기존 앱에 포함된 카카오 SDK 1.12.8-hotfix02를 실행했다. 운영 소스·설치된 본 앱·업무 데이터는 변경하지 않았다. 별도 계측 APK로 공개 SDK API만 호출했으며 안내 시작이나 GPS 모의주행은 하지 않았다.

## 조건

- 출발: 위도 35.0640682, 경도 128.9837168.
- 목적지: 다선초등학교 본교, 위도 35.0636823232284, 경도 128.985493965177.
- 공식 로컬 검색 1회로 본교 장소 ID `8223574`를 확인했다. 교무실·행정실·충전소 결과는 제외했다.
- 이름·주소·좌표·TIME 우선순위·기본 RPFlag(`*`)를 고정했다.
- 최초 앱 SDK 미리보기로 초기화한 뒤, 좌표만 → 같은 좌표+ID → 좌표만 순으로 별도 KNTrip을 생성하여 조회했다. 초기화 포함 SDK 경로 조회는 총 4회다.
- ID는 KNPOI의 공개 생성자 poiId 인수에 전달했다. 반환 KNTrip의 goal.poiId에 `8223574`가 유지되는 것까지 확인했다. 이 사실만으로 로컬 검색 ID의 SDK 내부 의미 호환성을 입증하지는 않는다.

## 실제 결과

| 요청 | 거리 | 시간 | 도착점 |
|---|---:|---:|---|
| 좌표만, 첫 번째 | 387m | 151초 | 남쪽 도로 |
| 같은 좌표 + 장소 ID | 387m | 151초 | 동일 |
| 좌표만, 재확인 | 387m | 151초 | 동일 |

세 결과의 폴리라인 13개 점 전체가 같다. 최종 도착점은 위도 `35.06304420897181`, 경도 `128.98491050078417`이다. 과거 SDK 남쪽 도착점과 사실상 같고, 앞서 카카오맵에서 본교 장소를 선택했을 때의 남쪽 접근 방향과 일치한다.

**이번 SDK 조건에서 장소 ID 추가의 개선 효과는 없었다. 좌표만으로도 남쪽 접근 경로가 나왔다.** 예전 학교 중심 좌표 REST의 북쪽 936m 결과와 SDK 결과를 구분해야 한다. 이번 실험은 장소 ID가 모든 장소에서 무효하다는 결론도, 실주행으로 정문 통과를 검증했다는 결론도 아니다. 교문 접근·개방·차량 진입 허용은 현장 미검증이다.
