# 국내 보행망 추가 조사와 다선초 실제 경로 비교

2026-10-26. 운영 앱과 서버는 변경하지 않았다.

## 다선초 — 이번에 실제 확인한 결과

기존 Android 통합 테스트에 고정된 출발점과 다선초 중심 좌표를 사용했다. 카카오맵 웹에서 같은 출발점으로 조회하고, 목적지를 검색 결과의 본교 장소로 선택했다. 학교병설유치원은 비교 대상에서 제외했다.

| 방식 | 차량 | 도보 | 도착 도로 |
|---|---|---|---|
| 카카오맵 웹에서 학교 장소 검색·선택 | 약 0.4km / 2분 | 491m / 9분 | 남쪽 |
| 카카오 REST에 학교 중심 좌표 입력 | 936m / 214초, 추천·TIME·DISTANCE 동일 | 491m / 546초, 큰길우선·최단 동일 | 차량 북쪽 / 도보 남쪽 |
| 국내 ITS + Valhalla에 학교 중심 좌표 입력 | 1,666m / 173.025초 | 국내 보행망 미확보 | 차량 북쪽 |
| OSM + Valhalla에 학교 중심 좌표 입력 | 832m / 84.085초 | 832m / 587.386초 | 둘 다 북쪽 |

카카오맵 웹도 최초에 중심 좌표 링크로 열었을 때는 약 0.9km의 북쪽 경로를 보였다. 검색 결과에서 **다선초등학교 본교 장소를 선택하고 자동차 탭을 다시 누르자** 약 0.4km의 남쪽 경로로 바뀌었다. 웹 화면과 카카오 REST의 입력 방식·장소 정보가 같지 않음을 구분해야 한다. 카카오의 내부 선택 알고리즘은 이 관측으로 단정하지 않는다.

현재 앱의 카카오 SDK를 이번에 다시 호출한 것은 아니다. ADB로 확인했으나 연결 기기가 없었다. 과거 2026-10-14 실기기 기록은 기본 SDK가 남쪽 도로 387m/139초였다. 이번 카카오맵 웹의 남쪽 결과와 방향이 같다.

추가 진단으로 과거 SDK의 남쪽 도착점을 직접 넣었다. OSM은 239m 경로를 반환했지만 끝점이 요청점에서 약 22.4m 떨어졌다. 국내 ITS는 1,041m 경로를 반환했고 끝점이 요청점에서 약 85.0m 떨어졌다. 이는 수동 진단이며 자동 출입구 보정을 구현했다는 뜻이 아니다. 실제 교문 진입·통행 가능성은 현장 검증하지 않았다.

**현재 자체 구성은 카카오 장소 선택과 같은 남쪽 도착을 재현하지 못한다.** 방문 순서를 계산할 때도 다른 도착 도로까지의 시간을 사용하면 비교가 왜곡될 수 있다. 이번 작업은 추천 순서용 이동시간 확보 연구이며, SDK 교체 작업이 아니다.

## 국내 보행 데이터 추가 조사

| 자료 | 실제 확인 | 보행망 구성에 부족한 부분 |
|---|---|---|
| 부산 도시공간정보 도로면 CSV | 원본 다운로드, 70,621행 중 사하구 5,010행 | 지형지물부호·도형ID·보도차도구분·시군구·면적만 있고 길의 좌표가 없음 |
| 부산 신호등 설치 횡단보도 CSV | 원본 다운로드, 3,815행 중 사하구 310행 | 위치 좌표와 크기는 있지만 횡단 양 끝점과 보행로 연결 정보가 없음 |
| 국토부 공공보행통로 SHP | 브이월드 자료 페이지 및 파일 C_UQ164_PW.zip 확인 | 다운로드 로그인 필요. 도시계획 통로 레이어로 전체 보행망을 보장하지 않음 |
| 국토정보플랫폼 수치지형도 | 공식 제공 경로·로그인 다운로드 안내 확인 | 이번 세션에서 로그인 원본을 확보하지 못함. 도형 확보 후에도 연결·접근 규칙 검증 필요 |
| 주소기반서비스 도로 도형·전자지도 | 공개 카탈로그 확인 | 전자지도는 신청·관할기관 승인 후 제공. 승인 자료 미확보 |
| KTDB 상세 도로망 Level6 | 공식 다운로드 목록·신청 구조 확인 | 이번에 부산 원본을 확보하지 못했고 완전한 보행망이라고 확인한 것도 아님 |
| 부산연구원 2022 도로중심선 | 공개 검색 결과 확인, 상세 페이지 및 개편 검색 접근 시 오류 | 원본을 받지 못했으며 보행 규칙 포함 여부 미검증 |

사용자는 현재 사용할 계정·승인 자료가 없다고 답했다. 로그인을 우회하거나 신청서를 제출하지 않았다. 국내 차량 도로를 임의로 양방향 보행 허용하지도 않았다.

**국내 데이터 + Valhalla의 도보 5곳·20곳 추천 순서 비교는 아직 완료하지 못했다.** 앞선 OSM 도보 결과를 국내 데이터 결과로 바꾸어 제시하지 않는다. 다음 필요한 입력은 부산/사하구의 보행로·횡단 연결·계단·출입구를 확인할 수 있는 실제 좌표 원본이다. 원본 확보 후에도 라우팅 가능성과 통행 규칙을 검증해야 한다.
