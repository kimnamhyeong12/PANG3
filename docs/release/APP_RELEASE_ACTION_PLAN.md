# 출시 실행 계획

기준일 2026-10-15. 공개 Android 출시 기준. P0는 공개 전 필수, P1은 안정성/운영 준비, P2는 후속 개선이다. `완료`는 적힌 범위에만 적용한다. R번호의 상세 근거는 [조사 결과](APP_RELEASE_READINESS_REPORT.md), 출처 S/C번호는 [근거 목록](APP_RELEASE_SOURCES.md) 참조.

## 오늘 시작 가능한 순서

1. 사용자: Play 계정 상태부터 확인하고 조건부 테스트 인원을 준비한다. 회사 계정으로 모두 바꾸는 작업은 지금 선행하지 않는다.
2. 서버 팀원: 서버 전달 문서대로 HTTPS·메일·복제 DB·파일 백업 준비를 병행한다. 현재 main 자동 배포는 저장소에 있지만 이 조사에서 main 변경/자동 배포하지 않았다. 검증 브랜치를 명시해 격리 배포할 절차를 먼저 만든다.
3. Codex: 승인된 운영 정보와 주소를 받아 P0 코드 변경을 별도 작업한다. 현재 조사 요청은 코드 변경 권한으로 확대하지 않는다.
4. 공동: 정식 빌드를 Play 내부 트랙에 설치해 테스트한다. 로컬 APK 설치 성공을 공개 배포 통과로 바꾸지 않는다.
5. 사용자/테스터: 조건부 비공개 테스트 → 프로덕션 접근 → 공개 심사. 외부 인증/심사는 대기 시간이 있고 승인 날짜를 보장할 수 없다.

최초 공개를 임의의 업데이트용 staged rollout과 동일하게 취급하지 않는다. Console에서 신규 출시/업데이트에 제공되는 배포 범위를 확인하고, 후속 업데이트에는 가능한 단계적 배포와 중지 절차를 사용한다.
