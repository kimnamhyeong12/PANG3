# 사용자 준비 목록

2026-10-15. 지금은 개인 계정으로 Android 출시 준비를 진행한다. 회사 설립과 모든 계정 교체부터 할 필요는 없다. 내가 코드로 만들 수 없는 본인 확인·계정 승인·운영 결정만 여기 구분했다.

## 1. 가장 먼저: Google Play 계정

- [ ] Play Console 개발자 계정 보유 여부, 개인/조직 유형, 생성일, 현재 인증 상태를 알려준다. 등록 비용은 US$25 일회성이다. 결제/본인 확인은 본인이 한다. [등록 안내](https://support.google.com/googleplay/android-developer/answer/6112435)
- [ ] Console이 요구하는 신원·연락처·결제 프로필·실물 Android 기기 확인을 마친다. 일반 사용자에게 공개되는 운영자 정보를 실제 Console 안내에서 확인한다. [기기 확인](https://support.google.com/googleplay/android-developer/answer/14316361)
- [ ] 2023-11-13 이후 생성 개인 계정에 해당하면 12명 이상을 준비하고 14일 연속 비공개 테스트 참여를 유지한다. 실제 사용 피드백을 받는다. 기간 후 프로덕션 접근을 신청하며 승인은 별도다. [개인 계정 테스트](https://support.google.com/googleplay/android-developer/answer/14151465)

개인 → 회사 전환 시에는 계정/앱 이전 조건을 다시 확인한다. 기존 앱 이전은 가능할 수 있지만 양 계정 상태·연결 서비스/결제/서명 설정이 따라온다. 이번 조사에서는 계정 이전하지 않았다. [앱 이전 공식 절차](https://support.google.com/googleplay/android-developer/answer/6230247)

## 2. 카카오와 Expo

- [ ] Kakao Developers의 실제 사용하는 앱, Android 패키지 `com.pang3.fieldworkhelper`, 허용 웹 도메인, 지도 활성화/Free badge/쿼터를 확인한다. 앱 키 값을 채팅에 복사할 필요는 없다.
- [ ] Codex와 출시 인증서를 확인한 뒤 Play 앱 서명 인증서의 키 해시를 등록한다. 로컬 테스트 인증서만 등록하면 Play 설치 앱에서 실패할 수 있다.
- [ ] 길찾기 SDK의 상용 사용 조건·무료량·추가 요금과 필요한 승인 여부를 해당 앱에 대해 확인한다. 공급자 문의가 필요하면 사용자 본인이 진행한다. 이번 조사에서 문의 메일을 보내지 않았다.
- [ ] Expo 프로젝트 owner의 실제 관리자와 팀원 접근권한을 정한다. 각자는 자기 로그인으로 같은 프로젝트에 접근한다. 같은 앱을 업데이트할 프로젝트/키를 고정하고 키 백업 책임자를 정한다. [Expo 계정 역할](https://docs.expo.dev/accounts/account-types/)

## 3. 운영자가 결정할 내용

| 결정 | 필요한 답 | 왜 필요한가 |
|---|---|---|
| 공개 범위 | 한국 공개 Play인지, 제한된 업무용 배포인지 | 계정/배포/정책 조건과 소개 문구 기준 |
| 운영 주체 | 실제 운영자 이름/표시 이름과 문의 메일 | 스토어 지원·정책·삭제 요청을 받을 곳 |
| 고객센터 | 지속적으로 확인할 이메일 주소와 응답 운영 | 여기서 말하는 ‘연락처’는 사용자의 계정 이메일이 아니라 앱 이용자 문의를 받을 창구 |
| 기록 보관 | 개인 보고서/사진, 공유 그룹 기록 각각 보관 기간·삭제 요청 처리 | 그룹 나가기 보존과 계정 삭제 의무를 함께 충족 |
| 공유 범위 | 그룹 구성원이 조회 가능한 정보/파일, 탈퇴 후 기록 표시 | 실제 앱 권한과 정책 일치 |
| 서비스 비용 | 월 예산, 사용량 초과 알림/유료 사용 허용 여부 | 지도·파일·서버 과금과 갑작스러운 제한 대응 |
| 기능 범위 | 경계 표시·음성·푸시 등을 공개 설명에 포함할지 | 포함하면 실제 운영 성공을 검증해야 함 |

운영자 정보·고객센터 주소는 내가 만들어낼 수 없다. 아직 주소가 없으므로 화면은 준비 중 상태다. 개인정보처리방침과 운영정책 초안은 내가 작성할 수 있지만 위 사실과 보관 결정은 사용자가 승인해야 한다.

계정 탈퇴 후 공유 기록을 남기는 기능은 현재 구현돼 있다. 그러나 사진 속 개인정보·개인 공간 자료까지 일괄 무기한 보관하겠다는 정책은 미확정이다. 식별정보 삭제/공유 문서 보관 범위와 정당한 사유를 정하고 실제 삭제 기능을 맞춰야 한다.

## 4. Play에 제출할 자료

- [ ] 앱 표시 이름, 한국어 짧은/전체 설명, 카테고리/태그, 국가/연령 대상. 방문지·사진·업무 보고서·단일 안내처럼 실제 제공하는 기능 중심으로 작성한다.
- [ ] 정식 앱 아이콘·스크린샷·필요한 그래픽. 로컬 서버 주소·디버그 문구·실사용자 이름/사진은 넣지 않는다. 자산 규격은 제출 당시 Console 요구와 대조한다.
- [ ] 지원 이메일, 공개 개인정보처리방침 URL, 앱 외부에서 계정 삭제를 요청할 URL.
- [ ] Data safety: 이름/아이디/이메일·위치·사진·문서/메모·푸시 및 SDK 처리 표를 Codex와 검토한다. 암호화/삭제 답변은 실제 구현과 운영 상태대로 한다.
- [ ] 앱 접근 정보: 심사자가 실제로 로그인해 개인/그룹/보고서 기능을 볼 수 있는 전용 계정과 재현 절차. 임시 비밀번호는 안전한 Console 입력으로 전달하고 문서에는 적지 않는다.
- [ ] location foreground service 설명/시작·종료 동영상과 해당 선언. 필요하지 않은 권한은 먼저 제거/검토한다.
- [ ] 콘텐츠 등급·광고 여부·결제 관련 선언. 코드에 결제가 없다고 향후 수익모델까지 확정하지 않는다.
- [ ] 내부 트랙/비공개 트랙 테스트 정보·피드백·사전 출시 보고서의 크래시/권한/호환 문제 처리.

양식 위치/요구 자료는 [앱 생성 및 설정](https://support.google.com/googleplay/android-developer/answer/9859152), [Data safety](https://support.google.com/googleplay/android-developer/answer/10787469?hl=en), [FGS 선언](https://support.google.com/googleplay/android-developer/answer/13392821)을 기준으로 Console에서 확인한다.

## 5. 본인이 해야 할 실제 사용 확인

Codex가 도구로 실제 차량 주행을 대신 검증할 수는 없다. 안전한 조건에서 별도 사용자/동승자가 안내 시작·화면 꺼짐·복귀·종료·앱 재실행·위치 권한 제한을 확인한다. 운전 중 기기를 직접 조작하지 않는다.

휴대폰 USB를 끊고 Play로 설치한 앱에서 Wi-Fi/모바일 데이터로 가입·사진 업로드·HWPX 열기까지 한다. HWPX는 ZIP/XML 검사에 더해 본인이 쓸 실제 한글 뷰어로 사진/문구/날짜/별도 파일 내용을 확인한다. 상세 순서는 [검증 계획](APP_RELEASE_VALIDATION_PLAN.md)이다.

## 6. 한 번에 알려주면 되는 정보

1. Play 계정은 이미 있는지, 개인/조직인지, 생성일과 인증/테스트 상태는 어떤지.
2. 한국 공개 출시가 맞는지, 지원 문의용 메일/표시 운영자와 개인·공유 보고서 보관 기준은 무엇인지.
3. 서버 팀원이 준비한 도메인/실제 AWS·DB·파일 백업/메일 상태와 월 예산은 무엇인지.
4. 현재 Expo owner를 관리하는 사람과 카카오 앱의 지도 Free badge/SDK 상용 승인 상태는 어떤지.

비밀번호·키·신분증 원본은 여기 답변에 올리지 않는다. 위 답이 없어도 코드/공식 정책 조사는 진행할 수 있지만 실제 계정 승인과 운영 설정 완료를 추정할 수는 없다.
