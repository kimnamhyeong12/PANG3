## 2. 지도와 길안내

- [ ] 방문지를 여러 개 등록했을 때 목록이 잘리고 겹치는 부분 없이 보인다.
- [ ] 긴 방문지명도 번호·날짜·버튼을 밀어내지 않는다.
- [ ] 경로 미리보기에서 거리·시간은 왼쪽, 차량·도보는 오른쪽에 표시된다.
- [ ] 차량 안내를 시작하면 방문지 선택창과 기본 하단 앱 네비바가 숨겨진다.
- [ ] 회전 안내에 화살표와 거리만 표시되고, 두 번째 회전 카드가 있을 때 모서리와 연결 부분이 자연스럽다.
- [ ] 실제 이동 시 남은 거리·시간과 회전 안내가 갱신된다. 정지 상태에서는 거리·시간이 계속 줄어들 필요가 없다.
- [ ] 현재 위치·목적지 아이콘과 주소가 하단 카드에서 정상적으로 전환되고 중앙 정렬된다.
- [ ] 경로 새로고침을 누르면 교통정보를 반영한 경로와 거리·시간이 갱신된다.
- [ ] 3D 화면에서는 `2D`, 2D 화면에서는 `3D` 버튼이 보이고 한 번 누르면 실제 지도 모드도 바뀐다.
- [ ] 지도를 드래그한 뒤 내 위치 버튼을 누르면 현재 위치 추적이 복구된다.
- [ ] 출발지와 목적지를 직선으로 잇는 불필요한 점선이 보이지 않는다.
- [ ] 주유소 버튼을 누르면 글자 대신 주유기 아이콘 마커가 표시된다.
- [ ] 주차장 버튼을 누르면 삼환아파트 주변 주차장 등 현재 지도 영역의 검색 결과가 표시된다.
- [ ] 지도를 이동하거나 확대·축소한 뒤 주변 장소 검색이 해당 영역에 맞게 갱신된다.
- [ ] 속도는 읽기 쉽고, 유효한 속도 정보가 없을 때 임의의 숫자를 표시하지 않는다.
- [ ] 단속 안내는 제한속도·남은 거리 중심으로 보이고, 삭제하기로 한 단속 설명·카메라 아이콘·과속방지턱 안내가 다시 나오지 않는다.

실제 이동 중 조작이 필요한 점검은 동승자가 수행하거나 안전하게 정차한 상태에서 진행한다.

## 3. 안내 메뉴와 화면 이동

- [ ] 하단 카드의 ☰를 누르면 위에 차량·도보·안내 종료, 아래에 지도·보고서·그룹·설정이 표시된다.
- [ ] 위·아래 메뉴의 글자 크기와 굵기가 어울리고, 차량·도보는 남색, 안내 종료는 빨간색으로 보인다.
- [ ] 메뉴와 안내 카드가 갤럭시 시스템 내비게이션 바에 가려지지 않는다.
- [ ] 메뉴를 닫으면 앱 네비바도 숨겨진다.
- [ ] 차량 안내 중 보고서에 갔다가 지도로 돌아와도 검은 화면 없이 지도·경로·안내가 복구된다.
- [ ] 그룹과 설정에 갔다 돌아오는 경우도 각각 확인한다.
- [ ] 위 왕복을 여러 번 반복해도 검은 화면·중복 음성·경로 초기화가 발생하지 않는다.
- [ ] 앱을 잠시 백그라운드로 보냈다가 돌아와도 지도와 안내가 정상적으로 복구된다.
- [ ] 차량↔도보 전환이 정상적으로 동작하고, 경로 조회에 실패하면 기존 안내가 유지된다.
- [ ] 안내 종료 후 일반 지도와 기본 하단 앱 네비바가 다시 표시된다.
- [ ] 첫 화면에는 불필요한 뒤로가기 버튼이 없고, 안쪽 화면에서는 이전 단계로 돌아간다.
- [ ] 첫 화면에서 Android 뒤로가기를 한 번 누르면 종료 안내, 제한 시간 안에 다시 누르면 앱 종료가 동작한다.

## 4. 보고서

- [ ] 작업 전은 `작업 전 · 선택 불가`로 표시되고 보고서 생성 대상으로 선택되지 않는다.
- [ ] 작업 중·작업 후는 카드로 선택 가능하며, 선택 테두리는 같은 남색으로 표시된다.
- [ ] 보고서 수정 아이콘을 누르면 카드 선택과 혼동 없이 작성 화면이 열린다.
- [ ] 사진·메모 입력과 저장 후 작업 상태가 의도대로 반영된다. 작업 후 자료가 있으면 저장 시 작업 후 상태가 반영되는지 확인한다.
- [ ] 작업 위치를 변경하고 저장하면 지도 마커 위치에도 반영된다.
- [ ] 사진 자르기·회전·펜이 동작하고, 되돌리기가 편집 순서대로 적용된다.
- [ ] 여러 보고서를 선택해 파일을 만들면 선택한 건수가 누락되지 않는다.
- [ ] 다운로드 화면에 방문지명·상태·날짜가 맞게 표시된다.
- [ ] HWPX 다운로드 후 실제 파일을 열 수 있고, 내용·사진·위치도가 맞게 들어 있다.
- [ ] 다운로드 실패 시 알기 쉬운 안내가 나오고 다시 시도할 수 있다.

## 5. 그룹 대시보드와 설정

- [ ] 대시보드·업무 이관·설정 탭의 폭이 균등하고, 탭 아래 내용의 시작 간격이 일관된다.
- [ ] 대시보드의 전체·작업 전·작업 중·작업 후 건수가 실제 업무와 맞는다.
- [ ] 지도 초기 범위가 그룹 생성 시 선택한 시·군·구에 맞고 불필요하게 멀리 축소되지 않는다.
- [ ] 작업 상태와 공통 업무 범례가 지도 바로 아래 한 줄로 보이며 지도를 가리지 않는다.
- [ ] 팀원현황 버튼과 작업자 선택 목록은 지도 안에서 정상적으로 열린다.
- [ ] 팀원 선택 후 담당 구역·방문지·업무 상태가 해당 팀원과 맞는다.
- [ ] 행정동 경계, 마커, 팀원 상세가 잘리거나 서로 겹치지 않는다.
- [ ] 설정에서 팀원 추가를 열었다가 다른 탭으로 갔다 돌아오면 검색창과 키보드가 불필요하게 다시 나타나지 않는다.
- [ ] 개인 업무공간과 공유 그룹을 전환했을 때 다른 공간의 정보가 섞이지 않는다.

## 6. 업무 이관과 신청 내역

- [ ] 업무 이관에서 팀원 목록과 담당 행정동이 정상적으로 표시된다.
- [ ] 본인은 구분되어 표시되고, 다른 팀원을 선택하면 해당 팀원에게 이관하는 화면이 열린다.
- [ ] 이관 내역 조회가 실패해도 정상 조회된 팀원·방문지까지 사라지지 않는다.
- [ ] 내가 받은 요청 중 아직 수락·거절하지 않은 요청이 최상단에 표시된다.
- [ ] 그 외 내역은 최신순으로 표시되고, 수락·거절 결과를 보낸 사람과 받은 사람 모두 확인할 수 있다.
- [ ] 처음 최대 20건이 보이고 더보기로 다음 최대 20건이 추가된다. 최대 40건 이후에는 더보기가 표시되지 않는다.
- [ ] 수락 후 담당자 변경이 지도와 보고서에 반영되고, 거절하면 기존 담당자가 유지된다.
- [ ] 이미 이관 대기 중인 방문지를 중복 신청하지 못한다. 화면에 보이지 않는 오래된 대기 요청도 포함해서 확인한다.
- [ ] 배포된 새 백엔드에서 실제로 20건씩 조회하는지 확인한다. 구버전 호환 처리로 화면만 나누는 상태와 구분한다.
- [ ] 테스트 DB에서 처리일 기준 30일이 지난 내역만 삭제되고, 오래된 미처리 요청과 최근 처리 내역은 유지되는지 확인한다.
- [ ] 자동 정리가 이관 요청과 연결 기록만 삭제하고 실제 방문지·보고서는 삭제하지 않는지 확인한다. 삭제 검증은 운영 데이터로 수행하지 않는다.

## 7. 그룹 보고서 전체보기

- [ ] 작업자·행정동 필터가 한 줄에 균등하게 배치된다.
- [ ] 필터 목록이 아래 내용을 밀지 않고 덮어서 열리며 선택·닫기가 잘 된다.
- [ ] 방문지 검색과 기간 조건이 함께 적용된다.
- [ ] 날짜 두 칸 사이에 `~`가 보이고 각각 독립적으로 날짜를 선택할 수 있다.
- [ ] 달력의 년·월 밑줄을 누르면 년·월 선택이 열리고, 이전·다음 달 이동도 정상 동작한다.
- [ ] 보고서 사이 구분선과 목록 간격이 일관되며 긴 방문지명도 읽을 수 있다.
- [ ] 조회 결과가 없거나 많을 때도 화면과 스크롤이 정상적이다.

## 8. 공통 마무리

- [ ] 화면 제목·뒤로가기·본문의 시작 위치가 화면마다 불필요하게 달라지지 않는다.
- [ ] 키보드를 열어도 입력칸과 주요 버튼이 가려지지 않는다.
- [ ] 긴 이름·주소·여러 행정동·큰 숫자가 버튼과 아이콘을 밀어내지 않는다.
- [ ] 작은 화면과 글자 크기를 키운 상태에서도 주요 기능을 사용할 수 있다.
- [ ] 로딩 중·결과 없음·서버 오류 상태가 서로 구분되고, 실패 후 다시 시도할 수 있다.
- [ ] 설정의 이름·아이디 표시, 개인정보 수정·로그아웃 흐름이 정상적이다.
- [ ] 설정에 재진입할 때 업무 알림 토글이 매번 새로 켜지는 것처럼 보이지 않는다.
- [ ] 네트워크를 끊었다 복구했을 때 기존 화면이 사라지거나 성공하지 않은 저장을 성공으로 안내하지 않는다.
