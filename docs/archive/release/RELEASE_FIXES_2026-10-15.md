## 하단 배경·안전 영역·개인 화면 정리

- 사진 편집의 펜 안내 문구를 제거했다. 하단 버튼 여백은 고정 높이 대신 실제 safe-area bottom inset을 사용하며 사진 편집 배경을 앱 배경으로 맞췄다.
- 기존 화면 루트의 translateY -15를 marginTop -15로 변경했다. 헤더 위치를 유지하면서 레이아웃이 하단까지 채워지도록 한다. 포함된 보고서 화면의 중복 이동과 보고서 작성 하단 버튼의 이전 보정도 제거했다.
- 앱 호스트와 하단 내비게이션 배경을 앱 배경으로 통일했다. Android 창 배경도 같은 색으로 설정하고 시스템 내비게이션의 추가 대비 배경을 비활성화했다.
- 개인 업무 헤더의 지역 표시와 내 진행 현황 카드를 제거했다. 작업 상태 통계와 지도, 개인 보고서 보관함은 유지한다.
- 그룹 목록에서 현재 작업공간이 다르면 첫 클릭은 전환만 하고, 이미 선택된 개인 업무공간을 두 번째 클릭해야 진입한다. 개인·그룹 모두 동일한 규칙을 회귀 검증했다.
- 프론트 기존 검증 17개 및 작업공간 전환 검증 1개 통과. Android 리소스·전체 APK 빌드 통과.

## 개인 업무공간과 개인 보고서 보관함

- 개인 업무공간 상단에 `내 개인 업무`와 계정의 시·도/구·군을 표시한다. 기존 개인 그룹도 조회 시 계정 근무지역과 동기화하고, 계정 변경 직후 카드와 화면은 사용자 지역을 우선 표시한다.
- 개인 업무공간은 `업무현황 / 보고서 보관함` 탭으로 구성한다. 업무현황은 기존 지도와 작업 전·중·완료 현황을 표시하며 개인 화면에는 팀원별 표를 표시하지 않는다.
- 개인 보관함은 기존 인증된 그룹 보고서 API를 재사용한다. 개인 그룹 구성원은 본인뿐이며 타 계정 조회는 차단된다. 방문지명/주소·행정동·작성 기간 검색, 본인 기록 수정, 개별 파일 다운로드를 제공한다.
- 보관함 첫 화면은 전체 기간이다. 기간 필터에 시작일/종료일을 선택할 수 있으며 `전체 기간`으로 초기화한다. 작업 전 기록도 표시하지만 다운로드는 작업 중·작업 후만 허용한다.
- 보관함에서 수정/다운로드를 열었다가 돌아오면 보관함 탭과 검색 상태를 유지하고 최신 기록을 다시 조회한다.
- 검증: 개인 그룹 생성 및 기존 그룹의 구·군 동기화, 본인 보고서 조회, 타 계정 접근 차단, 작업 전 다운로드 차단 통과. 프론트 검증 17개 및 백엔드 통합 18개+파일 격리 1개 통과.

- 1번 직접선택 UI 디자인 변경은 요청대로 보류.
- 직접선택 세션 시작 시 현재 지도 중심으로 선택 좌표를 초기화한다. 진행 중인 세션의 반복 명령은 선택 좌표를 유지한다. 버튼 문구는 `위치 선택`.
- 보고서 만들기는 선택한 보고서 확인을 거치지 않고 다운로드 화면으로 간다. ReportScreen.js와 관련 상태·이동 경로를 제거했다. 다운로드 화면에서 각 보고서의 이름·작업상태·작성 날짜를 조회해 표시한다. 보고서 1/HWPX 파일 기본 문구와 방문지별 파일 안내문을 제거했다. 개별 받기와 다중 파일 준비 기능은 유지한다.
- 다운로드 헤더를 다른 주요 페이지와 동일한 translateY -15에 맞추고 제목을 `보고서 다운로드`로 변경했다.
- 가입 이메일 입력을 근무지 주소 아래로 이동했다.
- 일반 설정: 이름과 @아이디 프로필, 작은 관리 버튼, 업무 알림 스위치, 공지사항, 고객센터/운영정책, 앱 관리(설정된 앱 버전), 로그아웃, 계정 탈퇴 순서.
- 계정 관리: 현재 비밀번호 검증 후 진입. 이름·새 비밀번호·근무지역·근무지·이메일 변경 UI. 아이디는 읽기 전용. 저장 API는 인증 사용자와 현재 비밀번호를 다시 확인한다. 비밀번호 변경 시 전체 세션을 만료시키고 재로그인하도록 한다. 이메일 변경은 기존 인증 메일 기능을 사용하며 SMTP 설정이 준비되어야 발송 가능하다.
- 업무 알림 OFF는 계정별 로컬 설정에 저장하고 푸시 토큰을 해제한다. 이후 자동 토큰 동기화가 다시 등록하지 않는다. 진행 중인 경로의 필수 안내 알림은 별도로 유지한다.
- 문의 이메일·운영정책은 사용자가 아직 없다고 답하여 준비 중 안내로 표시한다. 공지 데이터가 없으므로 등록된 공지 없음으로 표시한다.
- 보고서 만들기 문구를 줄이고 선택 불가 상태를 한 번만 표시한다. 사진 메모와 현장 메모 입력 힌트를 `메모를 입력하세요`로 통일했다. 선택한 공유 그룹 문구 제거 및 카드 축소. 개인 업무 현황의 작은 제목과 계정·개인업무 설명을 제거했다. 그룹 보고서 명칭을 `그룹 보고서 전체보기`로 변경했다.

검증: 프론트 스크립트 17개, 백엔드 인증·권한 통합 17개 및 파일 격리 1개, 기존 근무지 계약 검증 통과. Android APK 빌드 성공. 기존 로컬 H2 데이터를 유지해 서버를 재실행했다.
