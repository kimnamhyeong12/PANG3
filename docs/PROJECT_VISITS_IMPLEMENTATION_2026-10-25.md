# 프로젝트 방문지·지도 개선 구현 (2026-10-25)

## 사용자 동작
- 웹·앱은 같은 그룹 프로젝트를 사용한다. 팀원도 프로젝트 생성·수정, 업무 연결과 통합 보고서 관리를 할 수 있다. 다른 그룹 접근은 금지한다. 개인 공간은 기존 정책을 유지한다.
- 지도 + → 프로젝트: 생성, 저장된 장소 조회, 선택 등록/전체 등록. 진행 중인 장소도 체크할 수 있으며 선택/전체 등록 시 확인 후 별도 새 업무로 생성한다. 서버에서 뒤늦게 중복이 발견되면 제외된 장소만 확인 후 다시 등록한다. 중앙 카드에서 이름 입력·만들기와 목록을 바로 표시하며, 키보드가 열려도 위치와 목록 크기를 유지한다.
- 직접 방문지 등록: 프로젝트 선택과 업무유형 선택을 같은 줄에 둔다. 프로젝트 선택 시 장소를 보관하고 이번 업무를 생성·연결한다.
- project_places는 보관용 장소, task는 매번 생성되는 실제 업무다. 업무 삭제·완료로 장소를 삭제하지 않는다. 재등록은 담당자·미처리 상태를 새로 만들며 이전 사진·메모를 복사하지 않는다.
- 이관: 일반 업무는 행정동별 선택을 유지한다. 프로젝트를 고르면 행정동 구분 없이 단일 목록에서 개별/전체 선택한다. 업무 담당자만 바뀌며 프로젝트 연결은 유지한다.
- 보고서 작성은 개별 흐름 유지. 보고서 목록/보관함에서 선택 기록을 프로젝트에 연결한다. 업무 연결도 함께 추가하며, 보관용 장소는 추가하지 않는다. 기존 통합 보고서 기능을 사용한다.
- 별도 이전 방문 이력 화면이나 과거 방문 마커는 추가하지 않는다.

## 지도·기존 오류 수정
- 상단 카드: 그룹 + 차량/도보 아이콘 / 검색 / 방문지 N개·펼치기. 별도 순서 추천 버튼 없음.
- 이동수단별 추천 및 미리보기. 사용자가 안내 대상으로 지정해 만든 순서는 이동수단 변경으로 덮어쓰지 않는다.
- 안내 전 카드의 이동수단 선택은 확대 버튼으로 교체. 안내 중 카드 유지.
- 근무지 복귀 질문은 사용자별 한국 날짜 첫 안내에 한 번. 수락/거절을 저장해 재실행해도 유지하고 다음 날 다시 질문한다.
- 겹친 마커는 보고서와 같은 배치 규칙으로 뾰족한 번호 핀을 벌리고 원래 좌표 점과 선으로 연결한다. 실제 좌표·업무 ID·방문 순서는 유지한다.
- 가까운 목적지(25m 이내)는 경로 실패 대신 근처 안내와 작업 기록 진입을 제공한다.
- 완료 주소 재등록 허용, 진행 중 중복은 확인 제공. 완료 상태에서 작업 전/중으로 명시적 수정 허용.
- 공공데이터 등록 후 이전 선택 위치·카메라 상태 정리. 엑셀 창 재진입 초기화.
- 그룹 이름 필수 표시·안내 문구, 활동구역 선택 입력, 생성 완료 뒤 그룹 목록 이동을 수정한다.

## 저장소 및 API
- `GET /api/projects/{id}/places`: 보관 장소·진행 중 건수.
- `POST /api/projects/{id}/places/register`: placeIds 선택으로 새 업무 생성. 프로젝트 잠금으로 중복 요청을 직렬화한다.
- `POST /api/projects/{id}/link-reports`: progressIds의 업무를 프로젝트에 연결. 중복 연결 방지 및 그룹·보존기간 검사.
- PostgreSQL 시작 마이그레이션에 project_places와 task.project_place_id를 추가했다. 수동 마이그레이션 파일도 같은 내용을 포함한다. 기존 업무는 자동으로 보관 장소로 변환하지 않는다.

## 검증 및 적용
- 서버 관련 테스트 36개 통과 (프로젝트·반복 등록·권한·보고서·이관·상태·추천·보존기간).
- 앱 회귀 스크립트 16개 통과. 생성된 WebView 내부 스크립트 문법·날짜 경계·겹친 위치도 검사했다.
- 웹 Vite 빌드, Android Expo/Hermes 번들 생성 성공.
- 실제 단말 GPS·카카오 SDK 경로와 화면 배치는 아직 직접 검증하지 않았다. 서버 배포/재시작과 앱 새 빌드 적용이 필요하다.
- 도보 추천은 최대 20개 방문지에서 실제 도보 경로를 비교한다. 9곳 이상은 가까운 후보와 최종 추천 경로를 확인하는 방식으로 조회량을 줄이고, 동일 구간 캐시·동시 요청 합치기를 적용한다. 차량은 기존 최대 29개이며, 한도 초과·제공자 실패 시 거리 기준으로 대체한다. 개별 경로는 선택된 이동수단으로 조회한다.

## 2026-10-26 후속 검증

- 프로젝트 중앙 카드, 진행 중 장소 선택·확인·동시 등록 충돌 처리, 프로젝트 단일 목록 이관을 반영했다.
