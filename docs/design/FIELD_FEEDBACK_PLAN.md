# 추가 수정사항

## 1. 행정동 경계 표시 후 지도 조작 불가 문제 수정

현재 행정동을 선택해 SGIS 경계가 표시되면 지도가 고정되어

- 드래그
- 줌인
- 줌아웃

이 동작하지 않는 문제가 있음.

### 수정

행정동 경계는 지도 위에 표시만 하고 지도 조작을 막지 않도록 변경

경계가 표시된 상태에서도 반드시 다음 동작 가능

- 지도 드래그
- 줌인
- 줌아웃
- 지도 이동
- 마커 선택

---

## 2. 그룹 진입 시 업무현황 바로 표시

현재 그룹에 들어갔을 때 기본정보, 팀원관리 등의 화면을 먼저 보여주는 구조 변경

### 변경

**그룹 버튼 클릭 → 바로 업무현황 표시**

별도의 메뉴를 한 번 더 눌러 업무현황으로 들어가지 않도록 함.

---

## 3. 그룹 화면을 `작업현황 / 설정` 구조로 변경

그룹 화면 상단에 다음 두 개만 표시

- **작업현황**
- **설정**

### 작업현황

그룹에 들어왔을 때 기본 선택

기존 업무현황 화면을 그대로 표시

### 설정

그룹 관련 관리 기능 표시

---

## 4. 그룹 설정 메뉴 구성 변경

`설정`을 누르면 다음 메뉴 표시

- 팀원 관리
- 방문지/업무 이관
- 그룹 보고서 모아보기
- 그룹 설정

기본정보, 팀원관리 등을 그룹 첫 화면에서 바로 보여주지 않음.

---

## 5. 방문지 이관을 행정동 단위 전체 이관으로 변경

기존처럼 방문지를 하나씩 선택해서 넘기는 방식으로 만들지 않음.

### 변경

**특정 행정동에 포함된 현재 업무 전체를 한 번에 다른 팀원에게 이관**

예:

준호의 감천1동 업무

- A → 완료
- B → 작업 중
- C → 미처리

`감천1동 이관 → 남형 선택`

하면 A/B/C를 포함한 감천1동의 현재 업무 전체를 함께 이관

### 같이 유지할 데이터

- 완료 업무
- 작업 중 업무
- 미처리 업무
- 작업 전/중/후 사진
- 작성된 보고서
- 작성 중 데이터
- 메모
- 방문지 상태

즉 **개별 방문지 이관이 아니라 행정동 업무 전체 이관**으로 변경

---

## 6. 이관 수락 / 거절 유지

행정동 업무 이관 요청을 받은 팀원은

- 수락
- 거절

중 하나를 선택

### 수락

해당 행정동의 업무 전체 담당자가 새로운 팀원으로 변경

### 거절

기존 담당자와 데이터 그대로 유지

---

# 최종 그룹 화면 구조

**그룹**

→ **작업현황**
→ **설정**

### 작업현황
기존 업무현황 바로 표시

### 설정
- 팀원 관리
- 행정동 업무 이관
- 그룹 보고서 모아보기
- 그룹 설정
