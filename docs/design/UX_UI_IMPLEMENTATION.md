# UX/UI 코드 반영 — 2026-10-16

기준: 사용자가 확정한 [Figma](https://www.figma.com/design/Hn90PTisyf1C8AQDNob13J?node-id=38-445) 및 후속 수정 요청. 사진에 포함된 지도·경로·사진·가상 이름과 건수는 복사하지 않고 실제 앱 데이터와 SDK를 유지한다.

## 반영 범위

- 공통: 흰 배경, 남색 제목, 파란 주요 버튼, 정돈한 입력칸·여백·경계선. 기존 Safe Area 및 첫 화면/안쪽 화면 뒤로가기 구분을 유지한다.
- 상태: 작업 전 코랄, 작업 중 골드, 작업 후 청록. 목록은 연한 배경, 작은 상태 글자와 통계는 진한 색. 오류·탈퇴의 위험 색은 분리한다.
- 보고서 목록: 번호/날짜/상태만 간결하게 표시. 카드 전체로 선택·해제하고 선택 테두리는 남색. 수정 펜은 독립된 남색 버튼. 작업 전 선택 불가, 작업 중·후 선택 가능. 카드 사이 구분선, 선택 건수가 있는 생성 버튼.
- 작성: 위치도 표기, 중복 위치 안내 삭제, 동일 너비 작업 전·중·후 사진 탭, 실제 슬롯 인덱스를 유지한 편집·삭제·메모 처리. 저장 버튼은 본문 아래 고정. 보고서 초안 보관·위치 저장·업무 상태 변경은 유지한다.
- 다운로드: 파일별 실제 이름·상태·날짜 및 개별 다운로드. 전체 다운로드·부분 실패 재시도·플랫폼별 저장 흐름 유지.
- 지도: 검색 아래 접힌 가로 방문지 목록, 상태색 번호와 흰 숫자, 빨간 지도 마커. 안내 카드 하단 배치, 차량·도보·거리·시간을 한 줄로 구성. 기존 도착 위치 비교는 유지.
- 직접 선택: 현재 보고 있던 지도 중심에서 바로 시작하고, 지도 이동·위도/경도 입력을 모두 지원. 유효한 좌표만 지도에 반영하며 별도 고정·좌표 적용 버튼 없음. 확인 시 위치 선택. 이전 화면의 입력 요청은 새 세션 시작 시 초기화한다.
- 안내 중: SDK의 회전·차선·안전 안내를 유지하면서 우리 방문지 목록과 간결한 하단 정보를 위에 표시한다. 세 줄 메뉴는 차량·도보·안내 종료. 목적지/이동 방식 변경은 새 경로 성공 후 교체하여 실패 시 진행하던 안내를 보존한다. 안내 중 지도에서는 기본 하단 네비게이션을 감춘다.
- 그룹: 가로폭을 채우는 탭, 현재 업무 공간 강조, 간결한 가입 목록. 개인/그룹 전환·재진입 방식 유지. 전체 통계는 요약/완료율/상태별 수치/달력으로 정돈.
- 업무 현황: 상태 통계, 팀원 필터, 담당 구역과 공통 업무 범례 유지. 배정/이관/초대/탈퇴 기록 동작과 권한 유지.
- 보관함: 검색·작업자·행정동·날짜를 묶은 필터 영역, 겹쳐 열리는 필터, 동일 너비 작업자/행정동. 시작/종료 날짜를 따로 누르며 사이에 ~ 표시. 달력 년월은 밑줄, 연도→월→날짜 선택. 날짜 선택 즉시 반영·닫기, 범위 적용 버튼 없음.
- 설정·계정·가입·로그인·복구·그룹 생성·초대·배정·이관·근무지 선택·사진 편집·알림창: 같은 색상/헤더/입력/버튼/구분선 기준으로 확장. 실데이터 API와 인증 흐름은 유지한다.

## 검증과 한계

- 프론트 회귀 검사 23개. 보고서 카드 선택/수정 분리, 선택 대상 다운로드, 불완전·범위 밖 좌표 거부, 지도 드래그/직접 입력 동기화, 안내 중 이동 방식 변경 성공·실패를 추가 검증한다.
- 결과: 23개 검사 통과. 검색 강조 색상 검사는 확정된 브랜드 파란색으로 기대값을 갱신했다. Android Kotlin 컴파일 성공, 최종 Hermes 번들 내보내기 성공(970 모듈), UI 모듈 35개의 구문/스타일 참조 및 미정의 식별자 검사 통과, diff 공백 검사 통과.
- Android Kakao navigation Kotlin 컴파일 및 Android Hermes 내보내기로 JS/네이티브 연결 오류를 검사한다.
- UI 모듈 구문·스타일 참조와 `git diff --check`를 검사한다.
- 실제 Android 기기가 연결되지 않아 기기에서의 스크롤·키보드·SDK 오버레이·화면 비율 및 시각 일치 검증은 아직 완료하지 못했다. SDK 메뉴 숨김은 공개 bottomComponent/bottomMenuComponent를 사용하며 회전/차선/안전 화면은 유지한다.
- 새 SDK 메뉴 구성을 보려면 `cd frontend` 후 `npx expo run:android`로 네이티브 앱을 다시 빌드한다. JS 새로고침만으로는 Kotlin 변경이 반영되지 않는다.
- 서버 배포·DB 변경은 포함하지 않았다. 구현 후 사용자 요청에 따라 메인 브랜치에 커밋·푸시한다.
