# 웹 프로젝트 작업 공간

- 웹 프로젝트 상세는 프로젝트 소속 업무로 구성한 방문지 목록과 통합 보고서 목록으로 통합한다. 재사용 장소 목록은 상세 화면에 중복 표시하지 않는다. 지도·앱의 기존 재등록 API는 유지한다.
- 프로젝트 생성·이름 변경에서 기간을 묻지 않는다. 기존 기간 데이터는 삭제하지 않으며 기존 보고서 본문·지도·사진·목차 및 HTML/HWPX 양식은 그대로 사용한다.
- 새 보고서와 대상 변경은 프로젝트 화면 아래에서 처리한다. `ReportRecordFilters`는 건별 보고서와 프로젝트 보고서에서 공통으로 사용한다. 검색·시작일/종료일·현재 담당자·행정동 순서이며 담당자 바로 옆에 행정동을 배치한다. 검색 폭은 최대 420px이고 좁은 화면에서는 줄바꿈한다. 기본 기간은 건별 보고서처럼 전체이며 기록 작성일로 필터링한다.
- 대상 기록 선택은 한 번만 한다. 새 보고서의 `progressIds`와 기존 보고서의 `PUT /api/compiled-reports/{id}/items`는 그룹·완료·보존기간 검증, 프로젝트 연결, 보고서 항목 저장을 하나의 트랜잭션으로 처리한다. 대상 변경에는 `expectedUpdatedAt`을 전달한다.
- 프로젝트에서 제외하면 해당 소속 및 해당 프로젝트의 초안 항목에서 빠진다. 원본 업무·건별 보고서·확정본은 유지한다. 보고서에서 항목만 빼면 프로젝트 소속은 유지한다.
- 보고서 편집은 기존 양식을 재사용한다. 원본 제목·본문·사진 설명은 기존 담당자/그룹장 권한과 revision 검사를 거쳐 수정한다. 명시적으로 수정한 필드에 대해서만 초안의 과거 개별 덮어쓰기를 해제하며 다른 수정 내용과 확정본은 보존한다. 통합 보고서 제목·목차·순서는 보고서별로 유지한다.
- 다운로드 버튼 아래에서 HTML/HWPX를 선택한다. 기존 로컬 생성 엔진을 사용하고 진행 상태·실패·재시도를 표시한다. 자료 조회와 생성 화면 연결 실패를 20초 뒤 안내한다.
- 웹 설정의 알림은 대시보드 목록 필터가 아니라 앱 푸시 설정이므로 웹 메뉴에서 제거한다. 앱 설정과 서버 수신 선호, 대시보드 최근 알림 및 헤더 종 버튼은 유지한다.
- 앱 화면은 이번 작업에서 변경하지 않는다.

- 보고서 엔진 배포: 운영 Nginx의 `/report-runtime/*`가 웹 첫 화면으로 대체되는 문제를 수정한다. 웹 배포 시 실행 중 API 이미지의 공개 엔진·템플릿·Pyodide 의존성을 검증 후 웹 정적 디렉터리에 게시한다. 배포 후 공개 URL의 엔진 본문·스크립트 MIME·ZIP을 확인하며, HTML 대체 응답이나 누락 파일은 배포 검사를 실패시킨다. 브라우저 검사는 `REPORT_RUNTIME_FROM_WEB=1`로 실제 게시 산출물을 사용하고 건별 목록 HWPX·편집 HTML/HWPX 및 위치도·사진을 검증한다.

- 후속 정리: 건별보고서의 프로젝트 연결·소속 표시는 제거한다. 통합 보고서는 `건별보고서 필터링`으로 대상을 고르고 목차 구분 선택·중복 접기·저장 안내는 표시하지 않는다. 방문지에는 추가 및 우측 꺾쇠만 두며 다시 등록을 제거한다. 다운로드 메뉴는 외부 클릭·포커스 이동·Escape로 닫힌다.
- 보고서 변경 안내는 저장 중 알림을 제외하고 실제 보고서 updatedAt을 비교한 뒤 표시한다. 무관한 그룹 알림과 자신의 저장 반영은 충돌로 표시하지 않는다.

- 프로젝트 진입 흐름은 프로젝트 방문지 → 통합 보고서 목록 → 보고서 선택 후 건별 보고서 필터·목록 → 보고서 양식 순서다. 새 보고서는 목록 헤더 버튼으로 시작한다. 필터는 프로젝트 진입만으로 표시하지 않는다. 기존 양식·확정/버전·원본 수정은 유지한다.
- 필터의 결과 비율 표시는 제거하고 가운데 정렬한다. 범위 전환은 `프로젝트 외 업무 추가` ↔ `프로젝트 내 업무 추가`이며 각 범위에서 선택한 기록은 전환해도 유지한다. 방문지 추가 창에는 `n개 방문지 추가` 버튼만 표시하며, 상태 배지는 글자에 맞추고 목록만 스크롤한다. 방문지 접기/펼치기는 선택칸과 같은 선형 SVG 꺾쇠를 사용한다.

- 출력 정리: 통합보고서 목록에도 선택칸과 같은 SVG 꺾쇠를 사용한다. 웹 건별·통합 편집의 사진 설명 입력칸은 제거하되 원본의 기존 설명 데이터는 보존한다. 사진 그리드는 빈 열을 접어 카드 너비를 채운다.
- 통합 HWPX 개요는 프로젝트·작성날짜·총 건수·작성자로 구성하고 사업 기간/기록 기간/목차 구분을 표시하지 않는다. 항목의 사진표는 위치도 → 작업 전 → 작업 중 → 작업 후 순서다. HTML 상단도 기간·행정동별 대신 작성날짜를 표시한다. 작성날짜는 보고서 최초 생성일이며 과거 확정본에는 저장 내용을 바꾸지 않고 생성일 메타데이터만 보완한다.
- 건별보고서 카드에는 현재 담당자와 날짜만 표시한다. 보기·수정은 왼쪽, 다운로드는 오른쪽에 두고 다운로드 아래에서 HTML/HWPX를 고른다. 바깥 클릭·포커스 이동·Escape는 메뉴를 닫는다.
