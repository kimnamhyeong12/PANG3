# 현장 피드백 반영 — 2026-10-21

이번 범위는 1·2·3·4·7·8·11·12·13·14·15번이다. 10번 보고서 양식에 내 위치 추가는 보류한다. 프로젝트 생성·프로젝트 보고서·사진 형식 변경은 포함하지 않는다.

- 작업 시작 후 지도 마커와 목록에 작업 중 노란색을 반영한다. 검색·공공시설물·근무지 마커의 개별 색상은 유지한다.
- 완료 처리 시 현재 위치에서 남은 방문지를 재추천한다. 다음 방문지 미리보기는 재추천 결과 반영 후 연다. 실패 시 거리 기준 추천을 사용한다.
- 조치 완료 시각은 서버의 한국 시간 기준으로 저장하고 보고서 양식·보관함·HWPX에 표시한다. 보고서 이름이나 사진 수정으로 시각이 바뀌지 않는다. 과거 기록의 알 수 없는 완료 시각을 현재 시각으로 채우지 않는다.
- 보고서 이름을 양식에서 수정·저장한다. 보관함·다운로드 표시 이름·파일명·HWPX 제목에 반영한다.
- 상단 검색창은 주소·장소 검색을 바로 연다. 오른쪽 아래 ＋는 원형 등록 메뉴를 펼친다. 주소 검색·지도 선택·공공시설물·엑셀·사진·근무지 기능을 제공한다.
- 작업 전·중·후 사진과 메모를 한 화면에 세로로 표시하고 등록 여부를 표시한다.
- 보고서 목록 카드 본문은 상태와 관계없이 양식을 연다. 별도 체크박스는 보고서 생성 대상을 고른다. 기존 작업 전 기록의 다운로드 제한은 유지한다.
- 지도 목록·등록 시트·지역 선택 등은 바깥 터치로 닫힌다. 방문지 등록 중 닫은 내용은 ＋의 ‘작성 이어하기’로 복구한다.

## Android 도보 지도

카카오맵 네이티브 지도 SDK 2.15.2를 사용하며 기존 도보 REST API 경로를 그린다. 차량 KNSDK와 독립적으로 동작한다.

- 휴대폰 회전 센서의 방위각을 부드럽게 보정하여 지도 회전에 반영한다. GPS 이동 방향을 휴대폰 방향 대신 사용하지 않는다.
- 북쪽 고정 / 휴대폰 방향 추적 전환, 내 위치 복귀, 전체 경로 보기 버튼을 제공한다.
- 드래그·핀치가 끝난 뒤 5초 후 현재 위치로 돌아온다. 도보 기본 확대 수준은 네이티브 지도 줌 18이다. 기본 웹 지도의 도보 복귀 확대 수준은 레벨 3이다.
- 앱 비활성화·백그라운드·화면 종료 시 센서와 지도 라이프사이클을 정리한다.
- 네이티브 지도 시작 실패 시 기본 지도로 안내한다. 방향 센서가 없는 기기는 북쪽 고정을 사용한다.

새 네이티브 코드가 있으므로 APK 재빌드가 필요하다. 실제 휴대폰에서 방향 추적·나침반 보정·줌의 가독성·백그라운드 복귀는 별도로 확인해야 한다. 카카오 개발자 콘솔에 패키지명과 설치 APK의 키 해시를 등록하고 지도 SDK 사용 설정을 확인한다.

## 구글·카카오 로그인 설정

서버 설정 예시는 `backend/social-auth.env.example`에 있다. Google은 웹 애플리케이션 OAuth 클라이언트 ID/Secret, 카카오는 REST API 키와 활성화한 경우 Client Secret이 필요하다. 클라이언트 Secret은 앱 번들에 넣지 않는다.

각 콘솔에 아래 Redirect URI를 정확히 등록한다. `SOCIAL_PUBLIC_BASE_URL`은 실제 공개 HTTPS API 주소다.

```
https://your-api.example.com/api/auth/social/google/callback
https://your-api.example.com/api/auth/social/kakao/callback
```

앱은 시스템 브라우저에서 인증하고 `pang3://auth/social` 링크로 돌아온다. 서버는 state·Google PKCE를 검증하고 일회성 인증 코드를 서버에서 교환한다. 앱은 요청을 시작할 때만 받은 임의의 별도 비밀값으로 결과를 조회한다. 콜백 URL에는 앱 액세스/리프레시 토큰을 넣지 않는다. 요청 취소 시 대기 중 요청과 발급된 미수령 세션을 무효화한다. 결과 재조회는 동일한 세션을 반환한다.

최초 소셜 로그인은 별도 앱 계정을 만든다. 기존 사용자는 먼저 기존 계정에 로그인한 다음 설정 → 간편 로그인 연결에서 연결해야 기존 방문지·보고서를 유지한다. 이메일이나 표시 이름이 같다는 이유로 계정을 자동 병합하지 않는다. 다른 앱 계정에 연결된 소셜 계정은 다시 연결할 수 없다.

설정에서 연결된 소셜 계정으로 본인 확인 후 계정 관리·비밀번호 설정·탈퇴를 할 수 있다. 로그아웃은 기존 앱 세션을 폐기한다. 탈퇴 시 소셜 연결도 제거한다.

서버 설정이 비어 있는 공급자는 로그인 화면에서 ‘준비 중’으로 표시한다. 실제 공급자 인증 성공 여부는 콘솔 설정과 서버 배포 후 확인해야 한다.

## 배포 전 데이터베이스

운영 스키마 자동 변경이 꺼져 있으면 `backend/sql/field_feedback_migration.sql`을 먼저 실행한다. 보고서 이름·완료 시각, 비밀번호 로그인 여부, 소셜 계정 연결 테이블을 추가한다. 기존 완료 시각은 가장 최신 완료 기록에만 옮긴다. 개발 H2 프로필은 Hibernate 스키마 갱신을 사용한다.
