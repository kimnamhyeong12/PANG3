# 아이디 설정·변경

- 간편가입 계정은 자동 생성된 `social-UUID` 아이디를 화면에 표시하지 않는다. API의 `loginSetupRequired`로 설정 화면을 선택한다. 이전 서버 응답에는 자동 생성 형식 검사로 대응한다.
- 앱 계정 관리와 웹 내 계정에서 원하는 아이디 중복 확인, 비밀번호 입력·확인, 연결된 Google·카카오 계정 재인증 후 아이디·비밀번호를 함께 설정한다.
- 기존 사용자는 중복 확인 후 현재 비밀번호 또는 연결된 소셜 계정 재인증으로 아이디만 변경한다. 기존 비밀번호는 유지한다.
- `POST /api/users/{userId}/login-credentials`: `loginId`, `credential`, 간편가입 최초 설정의 `password`. 본인 세션과 본인에게 발급한 재인증 자격을 검사한다. 서버가 중복·형식·비밀번호를 재검사하므로 중복 확인 이후 선점되어도 저장되지 않는다.
- 사용자 행 잠금 및 고유 제약으로 변경을 처리한다. 사용자 번호, 소셜 연결, 그룹 및 현장 기록은 유지한다. 변경 완료 시 기존 로그인 세션과 소셜 재인증 자격을 폐기하고 다시 로그인한다.
- 자동 생성 아이디를 쓰는 기존 계정이 과거 비밀번호를 설정했더라도 사용할 아이디와 비밀번호를 소셜 재인증 후 함께 설정한다.
- 아이디·비밀번호 입력을 일반 계정 정보 저장과 분리한다. 설정·변경에 실패해도 입력은 유지하며, 오류 후 재시도할 수 있다.
